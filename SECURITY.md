# Security Policy

## Reporting Security Issues

We take the security of this website seriously. If you believe you have discovered a vulnerability, security flaw, or sensitive data exposure, please report it responsibly.

### Contact
Please send your report to:
- **Email**: [contact@krupalidonda.com](mailto:contact@krupalidonda.com)

Please include:
- A description of the vulnerability and potential impact.
- Exact steps to reproduce or proof-of-concept.
- Any relevant logs, URLs, or request headers.

### Scope
- Domain: `https://krupalidonda.com`
- Repository and static build infrastructure.

We will acknowledge receipt within 48 hours and work to validate and remediate valid findings promptly.
